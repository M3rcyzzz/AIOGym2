# 核验与门禁政策

Mercy 2026-11-02：“去掉不必要的哈希核验和过多的测试门禁”。只保留能防数据损坏或错误结论的检查；
正确性靠测试，改动时跑一次；可复现靠记录 git 提交。

| # | 检查 | 防什么 |
|---|---|---|
| 1 | 原子写入：JSON 和权重先写临时文件再改名 | 崩溃留下半个文件，被续跑或网站读到 |
| 2 | 数值有效性：观测、损失、梯度出现 NaN/Inf 就停，或跳过这一步 | 发散后继续写出垃圾权重和成绩 |
| 3 | 信息边界：模型只看公开测量、已发命令和自己的历史 | 信息泄漏让结论无效 |
| 4 | 代码版本：每次运行记下 git 提交 | 结果对不上代码 |
| 5 | 公平评测：各控制器在同一批装置和种子上配对比较；看到结果后不改门槛、不挑权重 | 单种子或事后选择造成的错误结论 |
| 6 | 网站发布：上传后核对归档，切换后页面能打开，只删受管目录里的旧版本 | 传输损坏、误删 |

不要加回：逐文件哈希冻结、准入或验收的收据链、保存后逐张量比对、逐项复算对账、精度门禁。
