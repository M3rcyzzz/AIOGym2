# AIOGym2：预训练通用先进过程控制器（APC）

> **One pretrained end-to-end neural network as a general Advanced Process Control (APC) controller.**
> Online progress: https://m3rcyzzz.club/aio/ · Model weights: [Hugging Face](https://huggingface.co/M3rcyzzz/AIO1) · [ModelScope](https://www.modelscope.cn/models/M3rcyzzz/AIO1)

AIOGym2 研究如何用**单一预训练端到端神经网络**直接承担多变量工业过程的先进过程控制（APC）。更换装置时只需要配置公开位号信息（被控变量 CV 的设定值、允许带宽、上下限与优先级；操纵变量/阀门 MV 的开度范围、单步速率限制；可选的常规回路配对与作用方向；采样周期）：

- **不做投运阶跃测试**：接入后直接闭环运行；
- **部署端无任何公式、在线辨识或优化求解器**：底层不串接 PID，没有递推最小二乘，也没有在线 DMC/MPC 求解器；
- **输入不含装置身份与物理方程**：模型仅凭历史含噪无量纲仪表读数，自行感知对象动态、纯滞后与工况漂移，直接输出每个阀门的下一步动作增量。

## 模型结构与训练方法

> 完整中英双语结构示意图见在线研究页面第 02 节：https://m3rcyzzz.club/aio/#method

### 部署端：单一端到端控制网络（`aio/seqnet.py`，约 1.29 亿活跃参数）

1. **无量纲统一编码**：每个被控变量/可测扰动（12 维特征）与每个阀门（6 维状态 + 上步动作）经共享编码器映射为 768 维向量，因此一套权重可适配任意回路数量；公布的回路配对仅作注意力可学习偏置。
2. **12 层时空交替注意力主干**（特征宽 768、12 个注意力头、预归一化残差连接）：
   - **因果时间注意力**：每通道回看自身过去 128 步历史，带旋转位置编码（RoPE）与 QK 归一化（QK-Norm）；推理时复用键值缓存（KV Cache），每步仅计算当前时刻；
   - **多滞后跨通道注意力**：直接跨越 1、3、8、16、24、36、48、64 步延迟回看全部通道，专门对齐大纯滞后（死时间）耦合对象；
   - **同刻跨通道交互注意力**：同一时刻全部被控量与阀门互相交互，协同解耦并按优先级处理约束让步；
   - **逐通道前馈网络（FFN）**：隐层宽 3,072，SiLU 激活。
3. **两条超越 128 步窗口的长时反馈记忆与 1 跳解耦通路**：
   - **通道长时记忆（64 维多尺度指数移动平均，衰减周期 4–2,048 步）**：捕获慢积分液位趋势与装置老化，既叠加到输出表征，又直接回馈注入下一步第 0 层输入；
   - **增益感知多尺度成对记忆与在途管道预测（8 阶因果状态空间滤波 + Gated DeltaNet）**：在公开仪表信号上逐拍 $O(1)$ 实时更新每一对“被控量–阀门”的因果影响权重与物理增益量级（每满速率步引起的带宽变化量），并将 8 尺度在途管道位移注入第 0 层构成多变量神经网络版 Smith 预测器，同时偏置全部 12 层通道与滞后注意力，并驱动输出前 1 跳多变量解耦消息传递。
4. **微幅精调直接动作输出头**：从每个阀门的输出向量经宽度自适应缩放（$1/\sqrt{768}$）、横跨三个数量级的乘性精调门控（兼顾高增益静默期微调与低增益大步幅）及双曲正切（`tanh`）限幅直接给出单步阀门动作增量。

### 训练端：纯真实代价穿过可微仿真器反传（`aio/train.py`，`aio/net.py`）

- **零模仿学习、纯真实控制代价**：在可微物理仿真器（`aio/sim/`）上并行推进 12×5、24×10、48×20 三种规模的随机装置（涵盖纯滞后、强耦合、非线性、积分液位、阀门粘滑与 20% 设备故障，75% 告知配对 + 25% 隐藏配对），将 64 步滚动窗口内的真实闭环代价穿过仿真器做截断反向传播（Truncated BPTT），并配合按通道灵敏度自适应缩放的轻量化探索噪声。
- **纯滞后感知特权价值网络（仅训练期，约 200 万参数，部署时彻底移除）**：在 64 步窗口末端读取仿真器无噪声真值（包括延迟管道中尚未抵达的在途动作、Smith 预测器式终态误差、积分液位漂移率与真实动态参数），以 4 个定长预测头监督拟合未来 64–256 步实际回放贴现代价（无时序差分自举发散），向控制网络提供提前收阀的远期梯度。
- **未告知配对探针与稳定优化**：仅在训练期挂接 75 参数线性探针校准多尺度成对记忆对未告知跨通道耦合的存在性、正反作用与物理增益量级辨识（部署时彻底移除），叠加仅惩罚阀门来回换向的反向平滑正则、带 0.5 下限的单样本梯度平衡、自适应梯度护栏、Muon + AdamW 混合优化器（余弦退火），并维护指数移动平均权重（EMA 0.97）用于稳定验证与发布。

## 代码结构

| 目录 / 文件 | 说明 |
|---|---|
| `aio/seqnet.py` | 端到端时空注意力控制网络（含多滞后路由、通道长时记忆回馈、成对关联记忆与 KV Cache 推理） |
| `aio/net.py` | 特权价值网络（`PrivCritic`）、部署控制器封装（`Controller`）与模型加载接口 |
| `aio/train.py` | 纯真实代价可微仿真端到端训练器（64 步截断 BPTT、定长多头 Critic、Muon+AdamW、EMA、多尺寸联合训练） |
| `aio/interface.py`、`aio/frame.py`、`aio/scale.py` | 公开无量纲接口编码、正反作用镜像与 0–100 统一评分尺 |
| `aio/sim/` | 可微过程控制仿真核心：随机多变量装置生成器、30 类经典机理装置、事件与故障引擎、评分与工程参照控制器、H4 基准测试与严谨性审计 |
| `release/` | Hugging Face 与 ModelScope 模型权重导出（`safetensors`）、独立运行加载器与双语模型卡 |
| `monitoring/` | 研究进展双语网站前端（`research-site/`）、Colab 远程长跑调度（`colab_job.py`）与进度推送（`train_status.py`） |
| `experiments/shared_rl_view/` | 研究进展网站数据构建、动态回放导出与发布脚本 |
| `reports/validation/` | 机理装置方程与物理守恒校验报告 |
| `docs/` | 仿真核心设计（`sim.md`）、基准标准（`standard.md`）、物理校验（`validation.md`）、任务严谨性检查清单（`task-rigor-checklist.md`） |
| `tests/` | 覆盖仿真物理、信息边界、网络推理/反传、训练保护与模型导出的自动化测试 |

## 快速上手

### 1. 安装依赖

```bash
# 先根据本机 GPU/CPU 环境安装 PyTorch，然后安装本仓库与测试/发布依赖：
pip install -e ".[test]"
```

### 2. 直接使用公开发布的预训练权重（无需克隆训练代码）

```python
# pip install torch numpy safetensors huggingface_hub  （国内可用 modelscope）
from huggingface_hub import snapshot_download
import sys
import numpy as np

path = snapshot_download("M3rcyzzz/AIO1")
sys.path.insert(0, path)
import modeling_aio as M

net = M.load(device="cpu")           # 或 device="cuda"
ctl = M.Controller(net)              # 每台装置一个实例；换装置时调用 ctl.reset()

packet = M.encode(
    values=y, previous=y_prev, target=sp, last_target=sp_prev,
    scale=cv_scale, lower=cv_low, upper=cv_high, tracking=is_tracked,
    command=u, last_command=u_prev, u_low=u_min, u_high=u_max,
    slew=du_max, pairing=pairing, dt=dt, sign=paired_gain_sign,
)
move = ctl.step(packet)              # 每路阀门动作增量，范围 [-1, 1]（占单步速率限比例）
u = np.clip(u + move[:len(u)] * du_max, u_min, u_max)
```

### 3. 运行仿真审计、测试与端到端训练

```bash
python -m aio.sim.audit                          # 仿真核心与任务严谨性审计
pytest tests                                     # 自动化测试套件

# 在单张 96 GB GPU 上启动纯真实代价端到端训练示例：
AIO_SEQ_AMP=1 AIO_SEQ_ROOMS=2 python -m aio.train \
  --out RUN --hours 16 --bc-iters 0 --window 64 --sim-window 64 --after 0 --stops \
  --priv-critic --fixed 64 --heads 4 --critic-lr 5e-4 --critic-iters 6 \
  --floor 0.5 --cost-w 0.03 --log-w 0.15 --smooth 0.25 --rev-smooth 2.0 \
  --unpaired .25 --pre-cost .05 --rel-id-coef 0.08 --noise 0.02 --faults .2 \
  --opt muon --muon-mom .95 --bias-lr-mult 4 --wd .05 \
  --lr 6e-5 --ema .97 --val-raw --seq d768,l12,h12,m64,g2,q1,u1,f1,r2 \
  --seq-ckpt --seq-window 128 --meter \
  --sizes 4:12x5@80 1:24x10@28 1:48x20@18 --val-sizes 24x10@64 48x20@32 --device cuda
```
