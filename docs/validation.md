# 仿真校验：对论文、对原版代码、对真实数据（11-10；BOPTEST、物性和塔 11-11）

十个机理装置（`aio/sim/plants.py`，#294）的方程、公布数字和守恒都对得上；
精馏塔 A 对 Skogestad 原版代码整条轨迹一致；按训练步长积分，单个决策的误差最大 0.37 带宽。
第一版校验查出的四处（放热 CSTR 飞温时积分算错、蒸发器液位贴在负的下界上继续出料、换热网络积分步偏粗、pH 的 pK2）
已在装置和引擎里改掉（#312，第二节），校验线程在改后的引擎上把十个装置整表重跑过，四处都确认修好；这四个装置上的旧参照要重跑（`docs/sim.md` 第十四节末）。
压力测试查出精度守卫的估计会漏（生物反应器、精馏塔 A），物性核对查出三处选型偏差（甲醇–水的焓、蒸汽、脱丁烷的挥发度不确定度）：装置线已改（#322，第二节末四行），校验线程在改后的引擎上独立重跑，数字一致。每个阀一步走满自己的速率限值时十个装置最大 0.50 带宽，一步动 20% 量程（限值的 4–10 倍）也都不到 1 带宽。
BOPTEST（暖通考场）已在本地跑通并接上现有模型做了零样本：散热器和商用单区回路能控，但不如考题自带的控制器；热泵地暖和两区公寓失败（第五节）。
它的四个供暖回路的响应形状原先都在先验之外；先验补了时间尺度（#344）后三个进到先验内，散热器仍在外（先验里像它的配对响应只有 0.9%）。真实记录（DaISy 五组）的特征现在全部在先验内。
三座按规格设计的塔对独立的逐级严格解：同一物性包下两端纯度差不到 0.16 带宽，单元方程和局部拟合没有问题。
换成不依赖该物性包的参考物性，差别出在物性选型：脱丁烷塔同纯度要多 11% 回流；甲醇–水塔热负荷改前偏高 3.5–5.5%，改后差 0.1%（第六节）。
三座塔按训练步长积分，计分的输出单决策最大差 0.09 带宽（第六节）。

工具在 `aio/sim/validate/`，结果在 `reports/validation/*.json`，第三方代码和数据不进仓库（`fetch.py`）。

- 方程对论文：照论文另写一遍（`papers.py`），在随机状态和输入上逐式比较，数字是最大相对差。
- 公布数字：稳态、时间常数、增益、零点、特征值，容差取论文的印刷精度（`checks.py`）。
- 守恒：按流程图另写的物料、能量账的残差。Van de Vusse、CSTR、生物反应器的副产物不是状态，没有可闭合的账。
- 积分误差：16 个训练回合 × 720 个决策，自整定PID 和老师各跑一遍，把记录下的输入重放到收敛参照
  （64 倍子步，自身对 LSODA 1e-10 相差 ≤ 2e-4 带宽；CSTR 只在飞温那几个决策上对过，差 0.01 带宽）。三个数取两种控制器里较大的。
  整回合一列是开环重放的累计漂移，开环不稳定的 CSTR 上它会发散，只看单决策。
  参照解写明子步数，不经精度守卫；运行时的一步带守卫（`docs/sim.md` 第十二节）。十行都是在改后的引擎（#312）上重跑的：改过的四个与装置线报的数一致，没改的六个里五个与第一版相同，精馏塔 A 的单决策最大误差从 0.26 降到 0.15（守卫起作用）。放热 CSTR 不做 LSODA 开环对照（开环发散，LSODA 走不完）。
- 加热炉、气网、换热网络是自建模型，没有论文或原版代码可对，只验了守恒和积分。

## 六、物性层和三座设计塔（11-11）

对象是物性层（`aio/sim/props.py`）和三座塔（`plants.LARGE`：`btcol`、`meoh`、`debut`）。表里是装置线改后（11-11）用同一套工具重跑的数；改前的数在第二节。
改后 `meoh` 和 `steam` 的纯组分物性、`meoh` 的混合热就取自下面的参照（这几项对上是按构造的），其余参照都不是引擎拟合的那一套：纯组分用各自的参考状态方程（CoolProp；水是 IAPWS-95）；
混合物用多流体 Helmholtz 模型（烷烃是 GERG-2008 的混合参数，苯–甲苯是 Bell–Lemmon 2016 按实测拟合的参数），甲醇–水用 UNIFAC-Dortmund 加参考蒸汽压。
