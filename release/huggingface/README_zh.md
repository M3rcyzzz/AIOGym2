# AIO1：预训练通用先进过程控制（APC）端到端神经网络

[English](README.md) | 中文

AIO1 是一张预训练的单一端到端神经网络（约 1.28 亿活跃运行参数），通过一套与具体装置无关的无量纲公开接口，直接承担多变量工业过程的先进过程控制（APC）：

- **不做投运阶跃测试**：接入陌生装置即可直接闭环控制；
- **部署端不含任何控制公式、辨识模块或优化求解器**：底层不串接 PID，没有最小二乘辨识，也没有在线 DMC/MPC 求解器；
- **不依赖装置身份或机理方程**：只接收归一化后的公开仪表读数（被控变量设定值、允许带宽、约束限位、优先级、可测扰动、阀门开度与速率限制、可选的常规回路配对与作用方向、控制周期），完全依靠自身闭环历史感知装置动态、纯滞后与工况漂移。

- **开源代码仓库**：[M3rcyzzz/AIOGym2](https://github.com/M3rcyzzz/AIOGym2)
- **在线研究进展与动态回放**：https://m3rcyzzz.club/aio/
- **ModelScope 镜像仓库**：[M3rcyzzz/AIO1](https://www.modelscope.cn/models/M3rcyzzz/AIO1)

## 现状说明（2026-11-28）

研究阶段公开检查点（全部为仿真结果、单种子，**尚未经过真实工业装置验证，切勿直接用于生产现场**）。本仓库始终仅保留当前最新的一份最优权重，每次更新直接覆盖旧版。

## 模型结构与训练方式

- **部署运行网络（约 1.29 亿活跃参数，权重文件总计约 1.31 亿参数）**：
  - 所有被控变量、可测扰动与阀门共享无量纲编码器，统一映射为 768 维向量，因此同一套权重无需改结构即可原生适配不同规模装置（联合训练覆盖 12×5、24×10 与 48×20）。
  - **12 层时空交替注意力主干**（宽 768、12 注意力头、预归一化残差连接），每层依次包含：因果时间注意力（回看自身 128 步历史，含旋转位置编码 RoPE、QK 归一化与推理键值缓存 KV Cache）、多滞后跨通道注意力（直接跨越 1、3、8、16、24、36、48、64 步回看全部通道以应对大纯滞后）、同刻跨通道交互注意力（多变量解耦与约束优先级让步），以及 3,072 宽前馈网络。
  - **两条跨步长记忆回馈支路 + 在途管道预测 + 1 跳解耦通路**：每通道 64 维多尺度指数移动平均记忆（遗忘周期 4–2,048 步）反馈注入第 0 层输入；每对（被控量，阀门）配备增益感知 8 阶因果状态空间滤波与对称 Gated DeltaNet 成对联想记忆，每步 $O(1)$ 在线更新因果影响权重与物理增益量级，将 8 尺度在途管道位移注入第 0 层构成多变量神经网络版 Smith 预测器，同时偏置全部 12 层的跨通道与多滞后注意力并驱动输出前 1 跳多变量解耦消息传递。
  - **微幅精调直接动作输出头**：经宽度缩放（$1/\sqrt{768}$）、横跨三数量级的乘性精调门控（按在线物理增益自适应缩放动作步幅）与双曲正切（`tanh`）限幅直接输出各阀门单步动作增量。
- **训练方式（纯真实代价、零模仿学习）**：
  - 不做模仿学习；直接将 64 步滚动窗口内的真实闭环控制代价（超带宽偏差、区间越限、失稳跳停与仅惩罚来回换向的反向平滑正则）穿过可微物理仿真器做截断反向传播，并配合按通道灵敏度缩放的轻量化探索噪声。
  - 64 步之后的远期代价由仅训练期使用的四头纯滞后特权价值网络（覆盖未来 64–256 步）引导，未告知跨通道耦合与物理增益量级由仅训练期 75 参数线性探针校准，两者在部署时均彻底移除。

## 验证成绩（2026-11-28，仿真）

统一 0–100 分刻度：**所有阀门不动 = 0 分**，**oracle MPC（始终知晓装置精确方程与实时真值）= 100 分**。全部控制器在同一批未见装置、事件与噪声上配对考核。

### 未见随机多变量装置（第十阶段第 80 轮最佳检查点）

| 装置规模（被控量 × 阀门） | 回合数 | AIO1（本份权重） | 自整定PID（参照） | 静态模型MPC（上参照） |
|---|---:|---:|---:|---:|
| **12×5 标准验证批** | 256 | **47.0**（带液位 **40.0** / 不带液位 **50.8**；对 PID 胜率 **46.5%**） | 48.6 | 91.2 |
| **24×10 大规模串联装置** | 64 | **57.7**（本阶段峰值 **58.8**，带液位高达 **60.7**、对 PID 胜率 **50.0%**） | 53.0 | 97.9 |
| **48×20 超大规模串联装置** | 32 | **63.1**（本阶段峰值 **64.6**，不带液位 **81.3**，越限率 **10.6%**） | 56.2 | 98.3 |

- 12×5 距自整定PID（48.6）仅差 **1.6 分**，带液位历史首破 40 达 **40.0**、不带液位达 **50.8**、事件后恢复达 **49.9**、事件前首破 40 达 **40.2**，不告知配对盲控达 **17.7**（本阶段峰值 **18.2**，为第八阶段上限的 4.7 倍）。
- 在 24×10 与 48×20 两档大规模耦合装置上分别领先自整定PID **+4.7 分**与 **+6.9 分**（本阶段峰值领先达 **+5.8** 与 **+8.4 分**）。

### 经典工业机理装置零样本考试（训练全程未见过任何机理装置）

用本份第十阶段第 80 轮权重在八类按文献方程构建的机理装置上各考 8 回合（共 64 回合、**零跳停**）：

- **八族平均分**：AIO1 **70.5**（**历史首次破 70；领先自整定PID 62.2 达 +8.3 分**；静态模型MPC **90.9**）。
- 分族成绩：精馏塔 A **94.7**（**反超静态模型MPC 81.2 达 +13.5 分**、超自整定PID 38.3 达 +56.4 分）、BSM1 污水处理 **93.0**（自整定PID 86.2）、建筑供暖 **74.5**（自整定PID 66.5）、四容水箱 **73.5**（领先自整定PID 66.5 达 +7.0 分）、田纳西–伊斯曼过程（TEP）**70.7**（历史首破 70；自整定PID 72.4）、pH 中和槽 **62.5**（**领先自整定PID 40.3 达 +22.2 分**）、放热反应釜 **50.7**（自整定PID 60.3）、脱丁烷塔 **44.5**（较第九阶段涨 +7.3 分；自整定PID 66.9）。

## 使用示例

```python
# pip install torch numpy safetensors huggingface_hub  （或 modelscope）
from huggingface_hub import snapshot_download   # ModelScope 用户：from modelscope import snapshot_download
import sys
import numpy as np

path = snapshot_download("M3rcyzzz/AIO1")
sys.path.insert(0, path)
import modeling_aio as M

net = M.load(device="cpu")           # 也支持 device="cuda" 或 "mps"
ctl = M.Controller(net)              # 每台装置一个实例，自动维护跨步记忆；换装置时调用 ctl.reset()

# 每个控制步传入当前公开仪表信号（numpy 数组）：
packet = M.encode(
    values=y, previous=y_prev, target=sp, last_target=sp_prev,
    scale=cv_scale, lower=cv_low, upper=cv_high, tracking=is_tracked,
    command=u, last_command=u_prev, u_low=u_min, u_high=u_max,
    slew=du_max, pairing=pairing, dt=dt,
    sign=paired_gain_sign,           # 每路阀门作用方向 +1 / -1，未知填 0；可选 dv=、weight=
)
move = ctl.step(packet)              # 每路阀门下一步动作增量，范围 [-1, 1]（占速率限比例）
u = np.clip(u + move[:len(u)] * du_max, u_min, u_max)
```

- **正反作用处理**：增益符号为 −1 的反作用回路会在 `Controller` 进出口自动镜像，无需手工变号。
- **任意规模适配**：默认 `encode()` 打包至多 12 个被控量 × 5 个阀门（未用通道自动掩码）；网络权重本身与规模无关，原生支持 `24×10`、`48×20` 等更大规模规范报文。
